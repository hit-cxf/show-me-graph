## 统一数据链路

网页和 Skill 客户端都访问同一个本地服务。论文、实体、关系、证据、备注、标签、分组、争议与反例支持增删改查；选中论文与当前分组共享保存。服务通过原子 JSON 文件持久化，用修订号检测过时写入，通过 SSE 通知页面获取新版本。前端主题、相机和临时主题筛选属于当前浏览器的显示偏好。

左栏全选有全选／全不选／部分选择状态。详情提供备注和标签维护；“管理知识库”是通用 JSON 编辑器。Agent 提供 Python 标准库客户端与标准 SKILL.md 包，详情见[安装说明](AGENT_SKILL.md)。
