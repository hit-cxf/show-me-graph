# Show Me Graph 1.0 本地服务

WebUI 与 Agent Skill 共用一个本地 HTTP 服务和持久化知识库。Git 仓库不包含论文、节点、关系或证据数据；全新克隆首次启动会创建空库，本机已有库不受影响。

```sh
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:4317。`npm start` 启动独立后台进程；重复执行不会重复启动。`npm run status` 查看状态，`npm stop` 停止，日志在 `.runtime/server-4317.log`。电脑重启后需重新执行 `npm start`；前台调试用 `npm run serve`。

## 维护和同步

- 左侧“全选”支持全选、全不选和部分选择状态；论文分组及选择范围通过 API 保存并同步。
- 节点详情可添加备注、添加或移除标签；左栏可按标签查找论文和技术实体。
- “管理知识库”提供论文、节点、关系、证据、备注、标签、分组、争议和反例的 JSON 编辑、新建与删除入口。字段约束见 [API.md](API.md)。当前编辑器面向研究原型使用，尚不是完整的表单式产品界面。
- 顶栏“偏好设置”可编辑知识库维护提示词，网页与 Agent 共用持久化偏好；配套 Skill 在维护开始时读取，写入前检查更新。空字符串表示不额外指定偏好，保存不会自动启动任务。
- API 写入经版本检查和原子持久化；网页通过 SSE 收到新版本。编辑中的草稿不会被外部更新覆盖，冲突保存需重新核对。
- [Agent Skill](../../skills/show-me-graph/SKILL.md) 的 Python 客户端只依赖标准库；[安装说明](../../docs/AGENT_SKILL.md)列出宿主发现路径与已验证范围。

持久化文件为 `.runtime/knowledge.json`。全新克隆首次运行创建空库；如果本机另有旧研究样本 `../corpus`，首次运行会从样本初始化。后续修改样本不会覆盖实时库。所有客户端连接同一服务进程，不要让多个服务进程并发打开同一 JSON 数据库。

## 可视化和原文

三维总览、论文横切面、单篇技术纵切面和跨论文技术切面保持可切换。论文显示为方框，技术节点显示为圆圈，完整名称在节点内换行并随相机距离缩放。所有连线采用平滑曲线；技术切面依据真实组成、使用、评测和结论关系自然分叉，同一逻辑深度内的节点可上下交错，缩窄子树宽度；阶段仍按已有先后关系从左到右排列。基础布局在不同深度之间留出一行节点高度的空白，上下交错不改变真实层级与父子关系。当前紧凑预览将所有节点中心间距统一缩至 70%（比原来缩小 30%），圆圈、方框和文字尺寸设置不变；多父关系和反馈边以淡色曲线保留，孤立节点独立显示。三维相机按实际节点的投影范围取景，远景论文框使用较小尺寸以减少遮挡。点击节点或使用右侧列表聚焦阅读，“查看全图”恢复完整范围，也可按技术主题筛选。所有可见节点均显示名称，共享实体在每篇论文下的出现位置各自保留名称。左侧栏保持固定宽度，右侧阅读栏可展开，展开或恢复宽度时保留图谱当前相机与中心；明亮/夜间主题、相机与切面是当前浏览器的显示偏好，学术记录、分组和选择范围是共享数据。

原文页码、高亮及哈希对应固定 PDF。定位通过不等于学术解释已人工核验。总览中的所属与共享身份连接是视图辅助线，不计入学术关系数。论文引用层按层次布局，技术流程允许反馈环。

## 检查

```sh
node --test api.test.mjs
node --test sync.test.mjs
node --test preferences.test.mjs
node --test technical-layout.test.mjs
npm run check
```

API 和同步测试使用临时数据库、独立端口，不修改当前知识库；依赖旧研究样本的测试在全新克隆中会跳过。`check.mjs` 检查 `SMG_URL` 指向的服务，默认当前 4317；它会短暂切换论文范围，结束后恢复。浏览器检查默认用本机 Google Chrome，可用 `SMG_BROWSER` 指定可执行文件。`npm run dev` 提供热更新，但仍需另开 `npm start` 为 API 提供服务。

当前版本没有后台自主调查调度器、通用 PDF 自动解析、Zotero 自动写入或备份恢复接口。研究由宿主 Agent 使用工具完成，再通过同一 API 入库。精确依赖见 `package-lock.json`。
